TASKS DIRECTORY
===============
Each file here represents one actionable task, scoped to a half-day coding
session (~3-4 hours of work). Tasks are generated by the task-breakdown agent
from notes in ../notes/.

File naming convention: TASK-YYYY-MM-DD-NNN-short-name.txt

Each task file contains:
- Task ID and title
- Description of what to implement
- Acceptance criteria
- Dependencies (if any)
- Status: PENDING / IN_PROGRESS / COMPLETE / BLOCKED
