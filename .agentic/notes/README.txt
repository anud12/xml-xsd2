NOTES DIRECTORY
===============
Place plain text (.txt) documents here. Each note should describe a feature,
bug fix, or improvement in plain language.

The task-breakdown agent reads notes from this folder and converts them
into actionable half-day tasks in the ../tasks/ directory.

Format suggestion:
- Title: one-line summary
- Description: what needs to happen
- Context: any relevant background
- Acceptance: how we know it's done
