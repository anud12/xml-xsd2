# String generator — Concepts

This document describes the core `StringGenerator` concept.

## Summary

`StringGenerator` is an **immutable**, **composable** grammar over a *regular language* of strings. It is used to generate coherent strings (names, item descriptors, etc.) and to test whether a given `string.of(...)` could have been generated by it. A generator is built with `oneOf` (deterministic choice) and `concat` (ordered composition), each taking an `Array<StringExpression>`. It exposes exactly two operations:

- `generateValue()` → `MaybeExpression<StringExpression>`: the generator→`StringExpression` conversion. Returns the generator's language expressed as a `StringExpression` grammar, present iff the language is non-empty.
- `isGeneratedBy(candidate)` → `ConditionExpression`: a **full-match** membership test ("could this string have been generated by this generator?"), as opposed to `StringExpression.isContaining` (substring).

Chaining generators is done by converting a sub-generator with `generateValue()`, unwrapping the resulting `Maybe`, and splicing the resulting `StringExpression` into the outer `oneOf`/`concat` array. A `StringExpression` always denotes at least one string (it is never empty); the only empty language is `oneOf([])`, which `generateValue()` surfaces as `maybe.none()` — the type system then forces the caller to unwrap before passing it downstream.

## Purpose

- Generate coherent, structured strings from a fixed grammar (e.g. a name = first + " " + last).
- Reuse coherent parts by sharing the same sub-generators across many generators.
- Verify membership: given a concrete `string.of(...)`, decide whether it is a member of the generator's language (data validation / world consistency).
- Preserve deterministic randomness via the instance RNG (see [randomness](../runtime/randomness.md)).

## Conversions (JS ↔ host)

- `oneOf`/`concat` accept `Array<StringExpression>`; a `null`/`undefined` element → error.
- `generateValue()` returns `MaybeExpression<StringExpression>`:
  - present (`maybe.of(grammar)`) when the language is non-empty — `grammar` is a `StringExpression` whose language equals the generator's language;
  - absent (`maybe.none()`) when the language is empty (`oneOf([])`).
- `isGeneratedBy(candidate: StringExpression)` returns a `ConditionExpression`.
- **Chaining**: because `oneOf`/`concat` accept `Array<StringExpression>` (not generators), a sub-generator is spliced in by converting it: `sub.generateValue().orElse(fallback)`. The mandatory unwrap is what surfaces — and forces handling of — the `oneOf([])` empty case at the use site.

## Language semantics

A `StringGenerator` denotes a **language** `L(gen)` (a set of strings):

- `L(oneOf(arr)) = ⋃ L(e) for e in arr` — deterministic choice (union).
- `L(concat(arr)) = L(arr[0]) · L(arr[1]) · … · L(arr[n-1])` — ordered concatenation (product).
- a leaf `StringExpression` `e` contributes `L(e)`: the set of concrete strings `e` can evaluate to (a literal `string.of(s)` → `{s}`; an expression with its own `oneOf` → the union of its branches).

**Invariant**: a `StringExpression` is never empty — it always denotes at least one string. Consequently the only way to obtain an empty language is `oneOf([])` (empty choice). `generateValue()` returns `maybe.none()` in that case; every other generator returns `maybe.of(grammar)`.

## `generateValue()`

- A **pure conversion** (no RNG). It returns the generator's language expressed as a `StringExpression` grammar — a lazy tree of `oneOf`/`concat`/literal nodes — wrapped in `Maybe`.
- The **concrete random string** is produced when the returned `StringExpression` is **evaluated** at an execution context: each `oneOf` node draws the instance RNG (see [randomness](../runtime/randomness.md)), in declaration order. So `nameGen.generateValue()` yields a grammar; evaluating that grammar yields a name.
- Chaining reuses this: `outer = sg.concat([ inner.generateValue().orElse(fallback), … ])` splices the inner grammar into the outer language, preserving the full composition.

## `isGeneratedBy(candidate)`

- **Full-match** membership: evaluate `candidate` to its set of concrete strings `S`; the condition is true iff `∃ s ∈ S : s ∈ L(gen)`. This is a whole-string match, NOT a substring (contrast `StringExpression.isContaining`).
- For a **literal** candidate (`string.of("Bo Jones")`), `S` is a single string → a definite membership result.
- For a **non-literal** candidate (its own `oneOf`), the result is **existential** over its evaluations.
- **Pure** (no RNG): it is a property of the languages, independent of the instance RNG.

## Host API (TypeScript)

### API Structure

**StringGeneratorApi** is the factory:
```ts
export type StringGeneratorApi = {
  /** Language = union of the elements' languages. Picks exactly one at evaluation (instance RNG). */
  oneOf: (oneOfArray: Array<StringExpression>) => StringGenerator,

  /** Language = ordered concatenation of the elements' languages. */
  concat: (elements: Array<StringExpression>) => StringGenerator,

  /** Marker for HostApi surfaces */
  type: StringGeneratorType,
}

export type StringGeneratorType = {
  // used when declaring argument types dynamically in HostApi clients
}
```

**StringGenerator** is the generator (exactly two operations):
```ts
export type StringGenerator = {
  /** The generator -> StringExpression conversion. Present with the language grammar
   *  when the language is non-empty; absent (maybe.none()) for oneOf([]).
   *  The concrete random string is produced when the returned StringExpression is evaluated. */
  generateValue: () => MaybeExpression<StringExpression>,

  /** Full-match membership as a condition: true iff `candidate` (evaluated) is in L(this).
   *  NOT substring. Non-literal candidate -> existential over its evaluations. Pure (no RNG). */
  isGeneratedBy: (candidate: StringExpression) => ConditionExpression,
}
```

### Implementation Notes

- A `StringGenerator` is **immutable**; `oneOf`/`concat` build new generators.
- Both factories accept `Array<StringExpression>`; generators are spliced in via `generateValue()` (see Conversions).
- `generateValue()` is a pure, lazy conversion; no RNG is drawn until the returned `StringExpression` is evaluated.
- `isGeneratedBy` reuses the automata/enumeration machinery specified for `StringExpression` (see [stringExpression](./stringExpression.md)), in full-match mode.

## Chaining

Because the arrays are `Array<StringExpression>`, a generator is composed into another by first converting it and unwrapping the `Maybe`:

```ts
const first = sg.oneOf([ string.of("Al"), string.of("Bo"), string.of("Cy") ]);
const last  = sg.oneOf([ string.of("Smith"), string.of("Jones") ]);
const nameGen = sg.concat([
  first.generateValue().orElse(string.of("")),
  string.of(" "),
  last.generateValue().orElse(string.of("")),
]);
```

`nameGen`'s language is `{Al, Bo, Cy} · " " · {Smith, Jones}`. If a sub-generator were `oneOf([])`, its `generateValue()` would be `maybe.none()` and the `.orElse(fallback)` decides what splices in — the empty case is therefore explicit at the use site, not silent.

## Membership algorithm (runtime)

Full-match membership `s ∈ L(gen)`, reusing the NFA/enumeration approach from [stringExpression](./stringExpression.md):

- Build an NFA over the grammar: literal → a single-accepting path, `concat` → product (sequential), `oneOf` → union, `ref` → expand (depth-capped, e.g. 16).
- **Full-match**: simulate on `s`; accept iff the **final** state is reached exactly after consuming **all** of `s`. (Contrast `isContaining`, which checks emptiness of an intersection for a substring.)
- Small-finite fast path: if the product of `oneOf` branch counts is under a threshold, enumerate all expansions and do a set-membership lookup.
- Apply size/time caps and heuristics for large grammars.

## Examples

```ts
const sg = hostApi.runtime.stringGenerator;
const { string } = hostApi.runtime;

// vocabulary as shared, coherent sub-generators
const first = sg.oneOf([ string.of("Al"), string.of("Bo"), string.of("Cy") ]);
const last  = sg.oneOf([ string.of("Smith"), string.of("Jones") ]);

// coherent name grammar: First + " " + Last
const nameGen = sg.concat([
  first.generateValue().orElse(string.of("")),
  string.of(" "),
  last.generateValue().orElse(string.of("")),
]);

// generate: the grammar, which evaluates to a concrete name at runtime
const nameExpr = nameGen.generateValue().orElse(string.of(""));
// e.g. evaluates to "Bo Jones"

// membership
nameGen.isGeneratedBy(string.of("Bo Jones"));   // true
nameGen.isGeneratedBy(string.of("Al Smith"));   // true
nameGen.isGeneratedBy(string.of("Jones"));      // false (substring only, not a full name)
nameGen.isGeneratedBy(string.of("Zed Jones"));  // false (not in vocabulary)

// coherence: reuse the same parts in a different structure
const nickname = sg.concat([
  first.generateValue().orElse(string.of("")),
  string.of("-"),
  last.generateValue().orElse(string.of("")),
]);
nickname.isGeneratedBy(string.of("Cy-Smith"));  // true
```

## Failure modes & Action items

- **Empty language**: only `oneOf([])`; `generateValue()` → `maybe.none()`. Callers must unwrap (`.orElse` / `.ifPresent` / `isCondition`) before splicing downstream — the type system enforces this.
- **Membership complexity**: NFA product construction can blow up. Provide enumeration for small finite languages, automata for larger ones, with sensible caps/timeouts (mirrors [stringExpression](./stringExpression.md)).
- **Non-literal candidate**: default is existential (∃ an evaluation that is a member). Consider an `isGeneratedByAll` (universal) variant if needed.
- **Determinism**: `generateValue()` is pure; the concrete string is produced at evaluation via the instance RNG (declaration-order draws across nested `oneOf`).

---

This spec aligns `StringGenerator` with the existing expression conventions (immutability, lazy evaluation, `MaybeExpression`/`ConditionExpression` results, deterministic instance RNG) while reusing the regular-language/automata machinery and adding full-match membership.
