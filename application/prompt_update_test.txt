Workflow:
    - Create a new git branch.
    - First create a todo so it can deleage to subagents
        - each todo must be prefixed with the agent responsible.
    - Add to the subagend resposibility that it also have to create a list of todo, similar to the parent.
    - If an error appears, delegate a subagent to fix the issue. This approach can be used recursivelly by the subagent to spawn sub-subagents etc.
    - commit all changes.

Note:
    - when calling a tool add a new line before calling it to better define the start point of the tool

    - when files are needed to be moved, to easily keep track of what changed please:
        - first create directory then commit
        - move file then commit
        - update file then commit
        - delete old file then commit
